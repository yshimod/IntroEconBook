実験説明

プレイヤーは「顧客」と「企業」です。

顧客の戦略は「仕事を発注しない」「仕事を発注する」です。

企業の戦略は「{{ C.CHOICE_LABEL_1 }}」「{{ C.CHOICE_LABEL_2 }}」です。

顧客が先手で、企業が後手の展開形ゲームだとします。

顧客が「仕事を発注しない」ならば、お互いに0ポイントです。

顧客が「仕事を発注する」を選び、企業が「{{ C.CHOICE_LABEL_1 }}」を選ぶと、顧客に2ポイント、企業に2ポイントです。

顧客が「仕事を発注する」を選び、企業が「{{ C.CHOICE_LABEL_2 }}」を選ぶと、顧客に-1ポイント、企業に4ポイントです。

{{ if C.NUM_ROUNDS == subsession.round_number }}

ただし、もし「{{ C.CHOICE_LABEL_2 }}」を選択した場合、この顧客から二度と仕事がもらえないとします。

{{ endif }}

※入力がなければ、コンピュータによりランダムに決定されます。
